# FamilyStock

Gestion familiale des livres, jeux et équipements : catalogue, emprunts, réservations et retours.

## Stack
- Next.js 15 / React 19 / TypeScript
- Tailwind CSS 4
- Déploiement prévu sur Vercel
- Supabase (authentification et base de données) à connecter dans une étape ultérieure

## Démarrage local
```bash
npm install
npm run dev
```

## État
V1.0 — interface de démonstration. Les données sont actuellement locales à la session du navigateur. L'authentification réelle, les invitations sécurisées, la base de données et les emails ne sont pas encore activés.

Ne pas utiliser de vraies données personnelles avant la mise en place de l'authentification et des règles d'accès.
